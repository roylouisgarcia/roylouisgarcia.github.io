RhythmBrownBox

A browser step-sequencer, shown as a three-stage evolution of the same idea — from a 2016 portfolio piece to a dependency-free, tested, accessible rebuild.

Version 1original build

The original build — NexusUI canvas widgets, Bootstrap layout, a main-thread scheduler, no tooling. Kept exactly as it was.

Version 22026 rebuild

A ground-up rebuild from a code audit: real BPM, saved & shareable patterns, a Web Worker clock, a fifth (snare) track, native keyboard-and screen-reader-accessible controls, and zero dependencies.

Version 3in design

In design. Adds an upload-your-own-sample track, per-track volume, swing, polymeter, a roving-tabindex grid and a real mobile layout — with the build methodology (FDD) chosen in a four-part write-up first.
