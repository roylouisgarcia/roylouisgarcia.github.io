## From a MOOC deliverable to a site I actually maintain

This portfolio started as a project for FreeCodeCamp's [Responsive Web Design course](https://www.freecodecamp.org/learn/responsive-web-design/responsive-web-design-projects/build-a-personal-portfolio-webpage), built as a single-page application that works on both desktop and mobile. I've kept adding to it since — new sections, new projects, new tools — rather than letting it freeze at "done."
